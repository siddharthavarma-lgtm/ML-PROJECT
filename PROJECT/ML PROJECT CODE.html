Project Objectives

  • Collect comprehensive historical Telugu movie metadata (Budget, Marketing, Genre, Runtime, Ratings, Vote Count).
  • Preprocess data by managing missing values, categorical encoding, and feature scaling.
  • Train an Elastic Net Regression model combining L1 and L2 penalties for optimal feature selection.
  • Evaluate prediction accuracy rigorously using MAE, MSE, RMSE, and R² Score metrics.

Why Elastic Net Regression?

Traditional linear regression often struggles when movie features (such as marketing budget, vote counts, and screen count) are highly correlated (multicollinearity).

Elastic Net combines the feature selection property of Lasso (L1) with the coefficient stability of Ridge (L2) regularization, yielding superior generalization across diverse Tollywood genres.

Elastic Net Loss Function

Elastic Net linear regression optimizes both L1 (Lasso) and L2 (Ridge) penalty terms simultaneously:

LElasticNet(β) = RSS + λ1 Σ |βj| + λ2 Σ βj²

This hybrid approach prevents overfitting on noise features while retaining robust feature grouping for high-budget Tollywood star vehicles.
